# Сайт «Більше ніж кєкс» для кав'ярень

Живий сайт: https://bilshenizhkeks.netlify.app , квіз: https://bilshenizhkeks.netlify.app/kviz/

## Як працює
- Усі файли сайту лежать у папці `site/`. Будь-яке збереження (commit) у гілку `main` Netlify публікує автоматично за 1–2 хвилини.
- Перед кожною публікацією запускається перевірка квізу (`perevirka-kvizu.js`). Якщо квіз втратив зв'язок із Google Формою заявок, публікація зупиняється, а на сайті лишається попередня версія.

## Правила для маркетолога
1. Можна самостійно: тексти й фото на головній (`site/index.html`, `site/img/`), коди пікселів і аналітики (Meta, GA4, TikTok) у `<head>`.
2. Не чіпати: квіз `site/kviz/`, адресу Google Форми, поля `entry.*`, файли `perevirka-kvizu.js` і `netlify.toml`. Правки квізу — через керуючого.
3. Великі зміни (структура сторінки, ціни, умови співпраці, контакти, домен) — лише після погодження керуючого. Для них створюйте окрему гілку і Pull Request, а не зберігайте одразу в `main`.
4. У кожному commit коротко пишіть, що змінено.
5. Не публікувати оптові ціни, назви конкурентів, вигадані відгуки та цифри.
